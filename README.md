# Локальный снимок — версия 0.2

Настольное приложение для Windows 10/11. Снимки сохраняются локально, без облака и подписки. Интерфейс на русском языке.

**[Скачать готовую версию для Windows x64](https://github.com/kuzmin-lemmi/LocalShot/releases/download/v0.2.0/LocalShot-0.2-Windows-x64.zip)** — распакуйте всю папку и запустите `LocalShot.exe`. Python не требуется. Инструкция: [ПЕРЕНОС.txt](ПЕРЕНОС.txt).

## Первый запуск

1. Установите **Python 3.11 или 3.12 для Windows** с https://www.python.org/downloads/windows/ . При установке оставьте включённым Python Launcher (`py`).
2. Распакуйте весь архив в постоянную папку, например `C:\Apps\LocalShot`. Не запускайте файлы непосредственно внутри ZIP.
3. Дважды щёлкните `START.bat`. При первом запуске он создаст отдельное окружение `.venv` и установит зависимости. Для этого нужен интернет. Дождитесь появления окна программы.
4. Нажмите «Выбрать папку сохранения». По умолчанию используется `Pictures\LocalShot` внутри домашней папки пользователя.
5. Для следующих запусков также используйте `START.bat`.

Установленные зависимости после первого запуска не требуют интернета. Если окно не появляется, откройте терминал в папке проекта и выполните `.venv\Scripts\python.exe launcher.py`. Журнал ошибок находится в `%LOCALAPPDATA%\LocalShot\logs\localshot.log`; сохраняются также две предыдущие копии журнала. Скрипт запуска делает не более одной попытки восстановления зависимостей.

В этой рабочей папке окружение `.venv` уже подготовлено на доступном Python 3.12.14 из среды Codex. Можно запускать `START.bat`. При переносе исходников на другой компьютер создайте новое окружение по инструкции выше: `.venv` зависит от пути базового Python и не является переносимой сборкой.

## Как пользоваться

| Действие | Управление |
| --- | --- |
| Выделить область | Ctrl+Alt+A |
| Снять текущий монитор целиком | Ctrl+Alt+S |
| Открыть папку снимков | Ctrl+Alt+O или двойной щелчок по значку возле часов |
| Отменить выделение | Esc |
| Сохранить в редакторе | Ctrl+S |
| Скопировать из редактора | Ctrl+C |
| Отменить правку | Ctrl+Z |
| Повторить правку | Ctrl+Y |
| Масштаб | Ctrl + колесо мыши или кнопки процентов |
| Показать снимок целиком | «Вписать в окно» |
| Перемещение по увеличенному снимку | Удерживать среднюю кнопку мыши и двигать мышь |

После выделения появится выбор: сохранить, редактировать, копировать или отменить. Панель действий в этой версии показана отдельным диалогом.

В редакторе есть стрелка, линия, рамка, сплошная заливка «Скрыть», размытие и текст. Для геометрических инструментов нажмите и протяните мышь. Во время движения показывается контур; итоговая правка применяется после отпускания кнопки. Для текста щёлкните в месте подписи и введите её. Цвет общий для инструментов; он показан на кнопке «Цвет», выбранный инструмент выделен. У линии и текста есть настройка размера. Масштаб просмотра не изменяет разрешение сохраняемого снимка. При открытии снимок вписывается в окно.

Чтобы убрать ответ из задания, используйте **«Скрыть»** и закройте все цифры прямоугольником. Можно выбрать белую заливку под фон страницы. Размытие не гарантирует, что ответ невозможно прочитать. В PNG сохраняются только итоговые пиксели, без исходного изображения и скрытых слоёв. Ранее сохранённые отдельные файлы автоматически не удаляются.

При закрытии редактора программа предложит сохранить снимок. Каждое сохранение создаёт новый PNG с датой, временем и микросекундами в имени. Закрытие главного окна оставляет программу в трее. Полностью завершить её можно через меню значка → «Выход». Если значок спрятан, откройте стрелку возле часов.

## Несколько мониторов

Для области можно выбрать любой из подключённых мониторов. Выделение ограничено **одним монитором**: протянуть область сразу через два экрана пока нельзя. «Весь текущий экран» снимает монитор, на котором находился курсор при вызове команды. Код учитывает соотношение логических координат Qt и физических пикселей изображения.

При отключении монитора или изменении его геометрии/масштаба активное выделение отменяется. Окна приложения восстанавливаются; захват можно повторить. Во время модального диалога новый захват не запускается.

## Автозапуск (по желанию)

Нажмите Win+R, введите `shell:startup`. Поместите в открывшуюся папку ярлык на `START.bat` (или на собранный `LocalShot.exe`). Для отключения удалите этот ярлык. Приложение самостоятельно не включает автозапуск.

## Сборка EXE

После успешного запуска через `START.bat` запустите `BUILD_EXE.bat` на Windows. Он установит PyInstaller и соберёт `dist\LocalShot\LocalShot.exe`. Сборка требует интернета для установки PyInstaller. Переносить нужно **всю папку** `dist\LocalShot`, включая `_internal`. На другом компьютере для этой сборки Python устанавливать не нужно.

Готовая переносимая сборка находится в `LocalShot-0.2-Windows-x64.zip`. Распакуйте всю папку `LocalShot` и запустите `LocalShot.exe`; Python на другом компьютере не нужен. Подробная инструкция включена в архив (`ПЕРЕНОС.txt`). Сборка предназначена для Windows 10/11 x64; проверена на текущей Windows 11.

## Статус проверки

На Windows проверены 15 автоматических тестов, редактор на синтетическом снимке 3840×2160, захват двух доступных мониторов при масштабе 100%, выделение области, отмена Esc, повторный захват и скрытие собственных окон. Проверен одновременный запуск двух процессов: создаётся один интерфейс, все три горячие клавиши успешно регистрируются, системный трей доступен.

Координаты масштабов 125%, 150% и 200%, отрицательная координата монитора и реакция на смену конфигурации проверены автоматическими тестами. Реальные смешанные масштабы, физическое отключение монитора, вызов сочетаний из сторонних приложений и меню трея требуют отдельной ручной проверки. Если сочетание занято, главное окно укажет конфликт; используйте кнопки или меню возле часов. Произвольная настройка сочетаний пока не добавлена. Подробности и команды проверки — в [VERIFICATION.md](VERIFICATION.md).

Редактирование растровое: после отпускания мыши стрелку нельзя отдельно передвинуть — отмените её через Ctrl+Z и нарисуйте снова. История отмены и повторения имеет общий лимит 25 состояний и 192 МиБ для сохранённых RGB-данных с учётом размера объектов. Текущее изображение, экранный кеш и временные буферы требуют дополнительной памяти. Если одно состояние превышает бюджет, отмена для него недоступна. Новая правка после отмены очищает ветку повторения. Защищённые видео и некоторые системные экраны могут не захватываться.

При ошибке записи недописанный PNG удаляется по возможности, снимок остаётся в редакторе. Если Windows не позволяет удалить недописанный файл, причина записывается в журнал. Уже существующие файлы не перезаписываются.

## Файлы проекта

- `app.py` — интерфейс, захват, горячие клавиши, сохранение и трей.
- `imaging.py` — рисование и скрытие фрагментов.
- `storage.py` — сохранение PNG и обработка неполной записи.
- `launcher.py` — запуск и журнал ошибок, включая ошибки загрузки Qt.
- `requirements.txt` — фиксированные зависимости.
- `START.bat` — установка и запуск.
- `BUILD_EXE.bat` — сборка на Windows.
- `test_localshot.py` — проверки (`python -m unittest -v`).
- `verify_editor.py`, `verify_capture.py`, `verify_startup.py` — воспроизводимые проверки редактора, захвата и запуска.
