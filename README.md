# Локальный снимок — первая версия 0.1

Настольное приложение для Windows 10/11. Снимки сохраняются локально, без облака и подписки. Интерфейс на русском языке.

## Первый запуск

1. Установите **Python 3.11 или 3.12 для Windows** с https://www.python.org/downloads/windows/ . При установке оставьте включённым Python Launcher (`py`).
2. Распакуйте весь архив в постоянную папку, например `C:\Apps\LocalShot`. Не запускайте файлы непосредственно внутри ZIP.
3. Дважды щёлкните `START.bat`. При первом запуске он создаст отдельное окружение `.venv` и установит зависимости. Для этого нужен интернет. Дождитесь появления окна программы.
4. Нажмите «Выбрать папку сохранения». По умолчанию используется `Pictures\LocalShot` внутри домашней папки пользователя.
5. Для следующих запусков также используйте `START.bat`.

Установленные зависимости после первого запуска не требуют интернета. Если окно не появляется, откройте терминал в папке проекта и выполните `.venv\Scripts\python.exe app.py`; текст ошибки можно отправить для исправления.

## Как пользоваться

| Действие | Управление |
| --- | --- |
| Выделить область | Ctrl+Alt+A |
| Снять текущий монитор целиком | Ctrl+Alt+S |
| Открыть папку снимков | Ctrl+Alt+O или двойной щелчок по значку возле часов |
| Отменить выделение | Esc |
| Сохранить в редакторе | Ctrl+S |
| Скопировать из редактора | Ctrl+C |
| Отменить правку | Ctrl+Z |

После выделения появится выбор: сохранить, редактировать, копировать или отменить. Панель действий в этой версии показана отдельным диалогом.

В редакторе есть стрелка, линия, рамка, сплошная заливка «Скрыть», размытие и текст. Для геометрических инструментов нажмите и протяните мышь. Для текста щёлкните в месте подписи и введите её. Цвет общий для инструментов; у линии и текста есть настройка размера. Масштаб просмотра не изменяет разрешение сохраняемого снимка.

Чтобы убрать ответ из задания, используйте **«Скрыть»** и закройте все цифры прямоугольником. Можно выбрать белую заливку под фон страницы. Размытие не гарантирует, что ответ невозможно прочитать. В PNG сохраняются только итоговые пиксели, без исходного изображения и скрытых слоёв. Ранее сохранённые отдельные файлы автоматически не удаляются.

При закрытии редактора программа предложит сохранить снимок. Каждое сохранение создаёт новый PNG с датой, временем и микросекундами в имени. Закрытие главного окна оставляет программу в трее. Полностью завершить её можно через меню значка → «Выход». Если значок спрятан, откройте стрелку возле часов.

## Несколько мониторов

Для области можно выбрать любой из подключённых мониторов. Выделение ограничено **одним монитором**: протянуть область сразу через два экрана пока нельзя. «Весь текущий экран» снимает монитор, на котором находился курсор при вызове команды. Код учитывает соотношение логических координат Qt и физических пикселей изображения.

## Автозапуск (по желанию)

Нажмите Win+R, введите `shell:startup`. Поместите в открывшуюся папку ярлык на `START.bat` (или на собранный `LocalShot.exe`). Для отключения удалите этот ярлык. Приложение самостоятельно не включает автозапуск.

## Сборка EXE

После успешного запуска через `START.bat` запустите `BUILD_EXE.bat` на Windows. Он установит PyInstaller и соберёт `dist\LocalShot\LocalShot.exe`. Сборка требует интернета для установки PyInstaller. Переносить нужно **всю папку** `dist\LocalShot`, включая `_internal`. На другом компьютере для этой сборки Python устанавливать не нужно.

Готовый Windows EXE в архив не включён: сборка и проверка на Windows в текущей среде недоступны.

## Статус проверки

В Linux со скрытым Qt-интерфейсом проверены: создание окна и редактора, преобразование пикселей, сплошное скрытие с сохранением PNG, отмена правки, сохранение снимка в выбранную папку. Есть автоматические тесты в `test_localshot.py`.

На Windows необходимо проверить реальные горячие клавиши, значок в трее, захват экрана, разные масштабы мониторов и сборку EXE. Это рабочий исходный прототип, а не прошедший проверку Windows-релиз. Если сочетание занято, главное окно укажет конфликт; используйте кнопки или меню в трее. Произвольная настройка сочетаний пока не добавлена.

Редактирование растровое: после отпускания мыши стрелку нельзя отдельно передвинуть — отмените её через Ctrl+Z и нарисуйте снова. История отмены ограничена 25 действиями и приблизительным бюджетом 192 МиБ; для очень больших снимков сохраняется как минимум одно действие. Защищённые видео и некоторые системные экраны могут не захватываться.

## Файлы проекта

- `app.py` — интерфейс, захват, горячие клавиши, сохранение и трей.
- `imaging.py` — рисование и скрытие фрагментов.
- `requirements.txt` — фиксированные зависимости.
- `START.bat` — установка и запуск.
- `BUILD_EXE.bat` — сборка на Windows.
- `test_localshot.py` — проверки (`python -m unittest -v`).
