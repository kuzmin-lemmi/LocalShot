ЛОКАЛЬНЫЙ СНИМОК 0.3.1 — WINDOWS 10/11, 64 БИТА (x64)

УСТАНОВКА БЕЗ МАСТЕРА
1. Скопируйте архив LocalShot-0.3.1-Windows-x64.zip на другой компьютер.
2. Нажмите на архив правой кнопкой мыши и выберите «Извлечь всё».
3. Поместите всю извлечённую папку LocalShot в постоянное место,
   например «Документы\LocalShot».
4. Откройте LocalShot.exe.
5. При желании создайте ярлык LocalShot.exe на рабочем столе.

Python, pip и подключение к интернету для работы не требуются.
Папка _internal должна оставаться рядом с LocalShot.exe.
Не запускайте программу непосредственно внутри ZIP.
Это переносимая сборка, отдельный установщик не требуется.

ПЕРВЫЙ ЗАПУСК
Нажмите «Выбрать папку сохранения». Если ничего не выбирать,
снимки сохраняются в Pictures\LocalShot домашней папки пользователя.
Снимки и настройки со старого компьютера в архив не включены.
Если нужны старые снимки, скопируйте их отдельно.

Программа автоматически включает автозапуск при входе в Windows
для текущего пользователя. При входе запускается в трее без главного окна.
Отключить можно галочкой «Запускать при входе в Windows» в главном окне.
Если переносите папку программы, запустите её из нового места один раз.

УПРАВЛЕНИЕ
Ctrl+Alt+A — выделить область.
Ctrl+Alt+S — весь монитор под курсором.
Ctrl+Alt+O — открыть папку снимков.
Esc — отменить выделение.
В редакторе: Ctrl+S — сохранить, Ctrl+C — копировать,
Ctrl+Z — отменить правку, Ctrl+Y — повторить.
Ctrl+колесо — масштаб, средняя кнопка — перемещение по снимку.
Ctrl+Shift+S — «Сохранить как», Ctrl+O — открыть изображение в редакторе.
Сочетания для захвата можно изменить через «Горячие клавиши…».

Закрытие главного окна оставляет программу возле часов.
Для полного завершения выберите «Выход» в меню значка в трее.

ДИАГНОСТИКА
Журнал ошибок: %LOCALAPPDATA%\LocalShot\logs\localshot.log
Сборка проверена на текущем компьютере с Windows 11.
На другом компьютере первый запуск и захват нужно проверить отдельно.

УДАЛЕНИЕ
Отключите «Запускать при входе в Windows», завершите программу через
«Выход», затем удалите её папку и ярлык.
Сохранённые снимки остаются в выбранной вами папке.
